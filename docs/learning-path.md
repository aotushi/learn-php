# PHP → Magento 学习路线

## 学习目标

完成后应当能够：

1. 使用现代 PHP 独立实现并测试业务功能。
2. 使用 MariaDB、Valkey、OpenSearch 和 RabbitMQ 处理电商常见数据场景。
3. 在 Linux 与 Docker 环境中部署、观察日志并排查故障。
4. 读懂 Magento 的模块、依赖注入、事件、插件、数据模型、后台配置和 API。
5. 开发 Magento 二次功能，完成版本升级、性能优化与线上问题定位。
6. 理解 B2C 外贸商城的商品、价格、库存、购物车、订单、支付、物流和多语言流程。

## 建议周期：24 周

每周投入 6–10 小时。已有编程经验时可以压缩 PHP 基础，但不要跳过测试、SQL、安全和 Magento 架构。

### 第 1–2 周：环境与 PHP 基本语法

- Docker 容器、镜像、挂载目录和常用命令。
- 标量类型、数组、运算符、条件、循环、函数和严格类型。
- 字符串、时间、JSON、文件处理与命令行参数。
- 练习：订单小计、折扣、税费、运费和币种格式化。

验收：输入一组商品和优惠规则，程序能输出清晰的订单金额明细；非法输入有明确错误。

### 第 3–4 周：现代 PHP 与面向对象

- 类、对象、可见性、构造函数、继承、组合和不可变对象。
- 接口、抽象类、Trait、枚举、异常和类型系统。
- 命名空间、Composer、PSR-4 自动加载与第三方包。
- SOLID 原则只结合实际重构学习，避免背术语。

验收：把金额计算重构为多个职责清晰、可替换、可测试的类。

### 第 5–6 周：Web、HTTP 与安全

- 请求、响应、状态码、Header、Cookie、Session 和 REST。
- HTML 表单、文件上传、输入验证、错误处理和日志。
- SQL 注入、XSS、CSRF、密码散列、权限检查和敏感信息管理。
- 练习：带验证和错误提示的商品登记页面。

验收：解释每个输入如何被验证、输出如何被转义、状态为何不会被跨站请求篡改。

### 第 7–8 周：MariaDB、SQL 与缓存

- 表设计、主键、外键、连接查询、聚合和事务。
- `EXPLAIN`、索引选择、慢查询与 N+1 查询。
- PDO、参数绑定、事务边界和数据迁移概念。
- Valkey/Redis 的键、过期、缓存穿透、会话和失效策略。

验收：为商品和订单设计数据表，完成安全查询；对查询给出索引依据；缓存更新后不会长期返回旧数据。

### 第 9–10 周：工程质量与问题解决

- PHPUnit：单元测试、集成测试、测试替身和边界用例。
- 调试器、结构化日志、堆栈、复现步骤和最小失败案例。
- Git 分支、提交、代码审查、静态检查和持续集成概念。
- 以测试保护一次较大的旧代码重构。

验收：拿到一个缺陷后能稳定复现、定位根因、修复并添加回归测试。

### 第 11–12 周：Linux、部署与前端协作

- 文件、权限、进程、端口、磁盘、内存、日志和定时任务。
- nginx、PHP-FPM、环境变量、健康检查和备份恢复概念。
- 浏览器开发者工具、JavaScript 模块、异步请求。
- Vue/React 的组件、属性、状态、事件和 API 调用基础。

验收：能从浏览器请求一路检查到 nginx、PHP、数据库；能修改一个前端表单并调试 API。

### 第 13–15 周：Magento 基础

- 店铺、网站、视图、商品类型、客户、购物车、订单和配置作用域。
- `app/code`、`vendor`、`pub`、`generated`、`var` 与命令行工具。
- 模块注册、`module.xml`、依赖注入、配置合并与生成代码。
- 缓存、索引器、Cron、后台管理和日志。

验收：从零安装 Magento，创建测试商品并完成下单；能说明一次页面请求经过的关键部分。

### 第 16–19 周：Magento 模块二次开发

- Service Contract、Repository、Model、Resource Model 与 Collection。
- 声明式数据库结构、数据补丁和配置补丁。
- Plugin、Observer、Preference 的适用边界；优先低耦合扩展点。
- 后台配置、ACL、系统配置、Admin UI、前台布局和模板。
- REST、GraphQL、队列消费者、Cron 和邮件。

验收：完成一个独立模块，包含配置、数据、业务规则、API、权限、测试和卸载说明；不修改 Magento 核心文件。

### 第 20–22 周：搜索、队列、性能与升级

- OpenSearch 索引、映射、分词、查询与 Magento 商品搜索。
- RabbitMQ 的交换机、队列、确认、重试、幂等和失败处理。
- 页面缓存、块缓存、Valkey、索引器、批处理和性能测量。
- Composer 升级、补丁、兼容性检查、数据备份、灰度和回滚。

验收：定位一个慢页面，给出测量前后的改进；设计不会重复执行副作用的异步任务；演练一次小版本升级。

### 第 23–24 周：B2C 外贸商城综合项目

从 [综合项目说明](../stages/10-capstone/README.md) 选择一个功能。建议做“客户分组价格 + 下单后异步通知”，它能串联商品、价格、客户、订单、后台配置、API、队列和测试。

验收：项目可安装、可演示、可测试、可回滚；README 能让另一位开发者在新环境中复现。

## 学习方法

- 每个概念先做最小示例，再放入电商业务场景。
- 所有金额使用明确的最小货币单位或可靠的十进制方案，避免浮点误差。
- 每个缺陷留下回归测试，每次性能改进保留测量数据。
- Magento 开发只通过模块扩展，不直接修改 `vendor` 中的核心代码。
- 每周写一次复盘：学会了什么、仍不确定什么、下周交付什么。

## 推荐资料顺序

1. PHP 官方手册：语言基础、类型、类与对象、异常、PDO。
2. Composer 文档：依赖、脚本、自动加载。
3. PHPUnit 文档：测试结构与断言。
4. Magento 官方安装、开发者和扩展指南。
5. MariaDB、OpenSearch、RabbitMQ、Valkey 各自的官方入门文档。

阅读资料必须配合本仓库练习；能解释、能实现、能排错才算掌握。
