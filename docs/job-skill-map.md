# 岗位能力映射

截图中的岗位核心是“Magento 外贸 B2C 网站的开发、升级和稳定运行”。下面将要求转换为可验证的学习成果。

| 岗位要求 | 对应阶段 | 可验证成果 |
| --- | --- | --- |
| 精通 PHP、独立开发 | 01–05 | 完成有类型、有异常处理、有测试的业务功能 |
| MySQL 与性能优化 | 04、09 | 设计商品/订单表，使用 `EXPLAIN` 优化真实查询 |
| Redis/NoSQL | 04、09 | 用 Valkey 做缓存和会话，处理过期与失效 |
| Linux 部署与运维 | 00、06、09 | 会检查进程、端口、日志、资源和服务健康状态 |
| Vue/React 基础 | 06 | 能修改组件、调用 API，并使用浏览器工具调试 |
| 复杂系统重构 | 02、05、09 | 先用测试保护行为，再分步重构并记录风险 |
| Magento 建站与功能开发 | 07、08 | 安装店铺并开发不改核心代码的独立模块 |
| 日常维护、BUG 修复 | 05、07、09 | 提供复现、根因、修复、回归测试和验证记录 |
| 版本升级 | 09 | 演练备份、兼容检查、升级、验证和回滚 |
| Elasticsearch | 09 | 理解搜索引擎概念，实际使用 Magento 2.4.8 支持的 OpenSearch |
| RabbitMQ | 09 | 实现可重试、幂等、可观察的异步任务 |
| 外贸独立站 | 07、10 | 处理多语言、多币种、税费、物流与时区场景 |

## 优先级

1. **第一优先：** PHP、SQL、HTTP、安全、测试和问题定位。这些决定是否能独立完成工作。
2. **第二优先：** Magento 架构与模块开发。先理解平台规则，再写功能。
3. **第三优先：** 缓存、搜索、队列、升级与性能。它们决定系统能否稳定运行。
4. **辅助能力：** Vue/React 基础和业务英语。目标是顺畅协作，不必先成为前端专家。

## 面试与作品集材料

最终至少保留三类可展示成果：

- 一个纯 PHP 小项目，展示代码质量、SQL 和测试。
- 一个 Magento 模块，展示配置、数据、API 与扩展点。
- 一份故障或性能案例报告，展示复现、分析、修复和验证过程。
