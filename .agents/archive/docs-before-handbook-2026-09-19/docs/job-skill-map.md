# 岗位能力映射

原岗位目标是 Magento 外贸 B2C 网站开发、升级和稳定运行。现在将学习拆成两层：第一阶段先获得通用 PHP 后台开发能力，第二阶段再学习 Magento 平台规则。

| 岗位要求 | 第一阶段基础 | 第二阶段专项 | 可验证成果 |
| --- | --- | --- | --- |
| PHP 独立开发 | 01–09 | 持续应用 | 有类型、验证、异常和测试的后台功能 |
| MySQL 与优化 | 04、08、09 | 12 | 事务正确，能用 `EXPLAIN` 说明索引 |
| Redis/NoSQL | 选做扩展 | 12 | 用 Valkey 做缓存并处理失效 |
| Linux 部署运维 | 00、05、06、09 | 12 | 会检查进程、端口、日志和服务健康 |
| Vue/React 基础 | 06、08、09 | Magento 前端按需补充 | Vue 后台能调用并展示 ThinkPHP API |
| 复杂系统重构 | 02、05、09 | 11、12 | 测试保护下的小步重构 |
| Magento 开发 | 通用业务基础 | 10、11、13 | 独立模块且不修改 Magento 核心 |
| BUG 修复 | 05、09 | 10–13 | 复现、根因、修复和回归测试完整 |
| 版本升级 | Composer 基础 | 12 | 兼容检查、备份、升级、验证和回滚 |
| 搜索与队列 | 延后 | 12、13 | OpenSearch 查询与幂等异步任务 |
| 外贸独立站 | 商品与 HTTP/SQL 基础 | 10、13 | 多语言、多币种、订单、税费和物流场景 |

## 优先级

1. 第一阶段优先 PHP 8.4、MySQL 8.4、HTTP、安全、测试和问题定位。
2. ThinkPHP 用于练习通用 Web 后台开发，不把框架方法当作 PHP 语言本身。
3. Vue 只复用后台页面和请求边界，避免重复学习已有前端能力。
4. Magento、OpenSearch、RabbitMQ 和高级认证进入第二阶段。

## 作品集

最终保留：

- 一个 ThinkPHP 电商运营后台 API，并与已有 Vue 后台联调；
- 一个 Magento 模块，展示配置、数据、API 和扩展点；
- 一份故障或性能案例报告，展示复现、分析、修复和验证。
