# 阶段 09：搜索、队列、性能、维护与升级

## OpenSearch

- 学习索引、文档、字段映射、分词、相关性和聚合。
- 观察 Magento 商品保存、索引器和搜索结果之间的关系。
- Magento 2.4.8 不支持 Elasticsearch；理解 Elasticsearch 7 到 OpenSearch 的历史关系即可，实际练习使用 OpenSearch 3。

```powershell
Invoke-RestMethod http://localhost:9200
Invoke-RestMethod http://localhost:9200/_cluster/health
```

## RabbitMQ

- 学习生产者、交换机、路由、队列、消费者和确认。
- 所有消费逻辑都考虑重试、重复消息、失败记录和可观察性。
- 用业务唯一键保证幂等，不假设消息只投递一次。

管理界面：<http://localhost:15672>

## 性能

按顺序排查，不凭感觉优化：

1. 固定可重复场景并记录基线。
2. 区分浏览器、网络、PHP、数据库、缓存、搜索和外部 API 时间。
3. 找到最大瓶颈，做一个可回滚改变。
4. 重复测量并检查功能副作用。

重点观察 Magento 缓存、全页缓存、索引器、Cron、SQL、批处理、图片和第三方接口。

## 升级演练

1. 阅读目标版本发布说明和不兼容变更。
2. 备份代码、数据库、媒体和配置，并实际验证恢复。
3. 检查第三方模块与 PHP/服务兼容性。
4. 在独立环境运行 Composer 更新与 `setup:upgrade`。
5. 运行自动测试和核心购物流程回归。
6. 记录上线顺序、维护窗口、监控指标和回滚条件。

## 验收

- 提交一份慢页面分析，包含修改前后数据。
- 实现一个重复投递也不会重复产生副作用的消费者。
- 完成一次补丁版本升级演练并成功恢复备份。
