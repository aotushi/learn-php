# 阶段 13：Magento B2C 外贸商城综合项目

## 推荐题目

开发“客户分组价格与下单后异步通知”模块：指定客户组在指定时间享受折扣；订单提交后由 RabbitMQ 异步生成一条待发送通知记录。

## 必须覆盖

- 后台配置：启停、客户组、折扣、起止时间。
- 金额规则：时区、四舍五入、税前/税后顺序清晰。
- 前台展示：商品、购物车和结账金额一致。
- 订单快照：后续规则变化不能改写历史订单金额。
- 异步任务：可重试、幂等、失败可查。
- API：至少一个查询接口，并带身份和权限检查。
- 测试：正常、边界、异常和回归场景。
- 运维：安装、配置、日志、监控、升级和回滚说明。

## 外贸场景检查

- 多语言与 Store View。
- 多币种展示与基础币种结算。
- 国家/地区税费和地址格式。
- 时区与促销生效时间。
- 海外配送和跟踪号。
- 邮件模板与隐私数据。
