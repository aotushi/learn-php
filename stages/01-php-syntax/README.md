# 阶段 01：PHP 语法与数据处理

## 学习内容

- 严格类型、变量、常量、字符串、数组与空值。
- 条件、循环、函数、参数、返回值和作用域。
- 日期、JSON、文件、命令行参数和异常基础。
- 电商金额使用“分”等最小货币单位，避免二进制浮点误差。

## 运行示例

```powershell
# 在 php 服务中，用 PHP 程序执行订单金额练习文件
docker compose exec php php stages/01-php-syntax/exercises/order_total.php
```

字段拆解：`exec` 来自 `execute`，表示在运行中的服务里执行；第一个 `php` 是服务名，第二个 `php` 是程序名，最后是交给程序的文件路径。完整说明见 [命令与缩写词典](../../docs/command-glossary.md)。

## 练习顺序

1. 增加一件数量为 3 的商品并确认小计。
2. 将折扣改为“满 500 元减 50 元”。
3. 增加运费规则：满 299 元免运费，否则 20 元。
4. 从 JSON 文件读取商品，而不是写死在代码中。
5. 对负价格、零数量、缺失字段给出明确错误。

## 阶段项目

编写 `checkout.php`：输入商品、客户等级、优惠码和目的国家，输出商品小计、折扣、运费、税费和总额。至少准备 6 个边界案例。

## 验收问题

- `===` 与 `==` 有什么不同？
- `null`、未定义变量和空字符串有何区别？
- 为什么金额不建议直接用 `float`？
- 哪些错误应该抛异常，哪些应该显示为用户输入错误？
