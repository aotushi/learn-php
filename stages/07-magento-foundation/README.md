# 阶段 07：Magento 基础

Magento 程序会由安装脚本下载到本目录下的 `app`，但不会提交到本学习项目。

## 第一部分：作为店铺使用者

1. 认识 Website、Store、Store View 和配置作用域。
2. 创建分类、简单商品、可配置商品和客户。
3. 设置库存、价格、税率、优惠、配送和支付方式。
4. 从前台完成一次注册、加购、结账、下单和后台处理。

## 第二部分：作为开发者

- 认识 `app/code`、`vendor`、`pub`、`var`、`generated`。
- 使用 `bin/magento` 管理模块、缓存、索引、Cron 和维护模式。
- 理解模块注册、配置合并、Object Manager 与依赖注入。
- 理解 Area、路由、Controller、Layout、Block、Template 和 ViewModel。
- 从 `var/log`、异常报告和容器日志定位问题。

## 必做实验

1. 分别清理配置缓存和整站缓存，观察差异。
2. 修改一个商品后检查索引器状态，再手工重建索引。
3. 打开模板提示，找到一个前台页面对应的模板来源。
4. 执行 Cron 并观察计划任务表变化。

## 验收

- 能完整演示一笔订单的生命周期。
- 能解释配置、缓存、索引和 Cron 各自解决什么问题。
- 能沿一次请求找到所属模块，不修改 `vendor` 中的核心代码。
