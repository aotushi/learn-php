# 阶段 05：测试、调试与重构

## 学习内容

- 单元测试、集成测试、端到端测试的边界。
- 正常、边界、异常和回归用例。
- 日志、堆栈、Xdebug、最小复现与假设验证。
- 小步重构、依赖隔离、代码审查和 Git 工作流。

## 训练流程

每个 BUG 固定使用以下记录：

1. 现象和影响范围。
2. 可重复的最小步骤。
3. 预期结果与实际结果。
4. 证据、假设和排除过程。
5. 根因，而不是表面报错。
6. 最小修复与回归测试。
7. 修复后的功能和副作用验证。

## 必做练习

- 给阶段 01 故意加入一个满减边界错误，先写失败测试再修复。
- 将一个 100 行函数拆分，但保证测试前后完全一致。
- 开启 Xdebug 单步观察金额计算。
- 为一次练习写简短代码审查，区分“必须修改”和“个人偏好”。

## 验收

提交一份缺陷报告。别人只按报告就能复现，并能看到修复前失败、修复后通过的测试。
