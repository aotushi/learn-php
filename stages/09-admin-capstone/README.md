# 阶段 09：一个可解释、可复现的小后台

第一阶段验收不是完整商城。只要求商品管理 + 简单登录/读写权限 + 验证/排错/测试。

## 五分钟演示

1. 按根 README 启动，admin 登录。
2. 新增自己的商品，修改价格，刷新列表，确认持久化。
3. 重复 SKU 或错误输入，展示失败状态；不伤及其他学习数据。
4. 只删除刚创建的商品，再用 viewer 登录；后端拒绝写操作。
5. 跑单元与接口检查，解释一次 Vue → ThinkPHP → MySQL 链路。
